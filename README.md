# Administrador de Estudiantes

Hoja de trabajo Semana 15 – Programación II (Listas Enlazadas Simples). Aplicación de consola en C# que administra estudiantes con una lista enlazada simple implementada manualmente (clases `Nodo` y `ListaEstudiantes`).

## Funciones
1. Crear (inserta al final, sin carnés duplicados, promedio entre 0 y 100)
2. Listar (genera un archivo `lista_<fecha_hora>.txt` distinto en cada ejecución)
3. Buscar por carné
4. Actualizar nombre, carrera o promedio
5. Eliminar por carné (primer nodo, intermedio o último)
6. Ordenar por nombre (A-Z), algoritmo manual
7. Ordenar por promedio (mayor a menor), algoritmo manual
8. Reporte de estadísticas (guardado en `reporte_estadisticas.txt`)
9. Salir

## Ejecución
```bash
dotnet run
```
